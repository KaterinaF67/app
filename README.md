# Система — итоговый репозиторий

В одном репозитории лежат три варианта одного приложения:

- `web/` — сайт/PWA для GitHub Pages; устанавливается на Android и Windows через браузер.
- `android/` — нативная Android-оболочка; GitHub Actions собирает `app-debug.apk`.
- `windows/` — настоящее отдельное Windows-приложение на Electron; GitHub Actions собирает установщик и portable `.exe`.

## Что делать на GitHub

На странице с шаблонами Actions **ничего из списка выбирать не нужно**. В этом репозитории уже есть готовые workflow-файлы в `.github/workflows/`.

1. Распакуйте ZIP.
2. Загрузите в корень репозитория всё содержимое распакованной папки, включая `.github`, `web`, `android`, `windows` и `README.md`.
3. После коммита откройте вкладку **Actions**. Появятся три workflow:
   - `Deploy Systema PWA`
   - `Build Android APK`
   - `Build Windows app`

## Сайт/PWA

1. Откройте `Settings → Pages`.
2. В `Build and deployment → Source` выберите `GitHub Actions`.
3. Откройте `Actions → Deploy Systema PWA → Run workflow`.
4. После успешной сборки ссылка появится в workflow и в `Settings → Pages`.

### Установка на Android

Откройте опубликованную ссылку в Chrome → меню `⋮` → `Установить приложение` или `Добавить на главный экран`.

### Установка на Windows

Откройте ссылку в Edge → меню `…` → `Приложения` → `Установить Система`.

## Получить Android APK

1. `Actions → Build Android APK`.
2. Нажмите `Run workflow`.
3. Откройте завершённый запуск.
4. Внизу в разделе `Artifacts` скачайте `Systema-Android-APK`.
5. Распакуйте архив и установите `app-debug.apk` на телефон.

Android может попросить разрешить установку приложений из браузера/файлового менеджера.

## Получить Windows-приложение

1. `Actions → Build Windows app`.
2. Нажмите `Run workflow`.
3. В завершённом запуске скачайте артефакт `Systema-Windows`.
4. Внутри будут установщик и portable `.exe`.

Это Electron-приложение с собственным окном. Оно не запускает Microsoft Edge отдельным процессом.

## Где хранятся данные

Эта версия локальная, без аккаунта и облачной синхронизации.

- PWA: хранилище конкретного браузера на конкретном устройстве.
- Android APK: внутренние данные приложения Android; удаление приложения удалит локальную базу.
- Windows: `%APPDATA%\Systema`.

На телефоне и компьютере базы отдельные. Для переноса используйте `Настройки → Экспорт JSON`, затем импортируйте JSON на другом устройстве.

## Важно

Перед удалением приложения, очисткой браузера или переустановкой Windows сохраните JSON-резервную копию.
